# TimeSequence 微信小程序

**Created**: 2025-11-21  
**Status**: Draft

---

## Overview

TimeSequence 是一款集成了传统黄历查询、现代日历、节假日安排以及个人倒数日/纪念日功能的时间管理微信小程序。它采用清新、理性的蓝绿色调风格，融合卡片式设计与扁平化图标，为用户提供便捷的时间查询和管理服务。

## User Scenarios & Testing

### Primary User Flow

#### 场景 1: 查看今日黄历
1. 用户打开小程序，默认进入首页
2. 首页顶部显示当天的公历日期和农历日期
3. 页面展示"今日黄历"卡片，包含宜忌事项和干支信息
4. 用户可以通过左右切换按钮查看其他日期的黄历

#### 场景 2: 查看月历和节假日
1. 用户点击底部导航栏的"月历"Tab
2. 显示当月的日历网格，节假日标记"休"或"班"
3. 用户点击某个日期，底部弹出详情面板显示该日的宜忌胶囊列表
4. 用户可以左右滑动切换月份

#### 场景 3: 管理个人倒数日
1. 用户点击底部导航栏的"倒数日"Tab
2. 查看所有倒数日/纪念日列表
3. 用户点击右下角的悬浮"+"按钮添加新事件
4. 填写事件标题、日期、分类等信息后提交
5. 返回列表查看新添加的事件及剩余天数

#### 场景 4: 查看节假日安排
1. 用户点击底部导航栏的"节假日"Tab
2. 以时间轴布局查看upcoming节假日
3. 每个节假日卡片显示放假时间、天数和调休信息
4. 用户可以看到距离下一个假期还有多少天

#### 场景 5: 查看详细黄历信息
1. 用户点击底部导航栏的"黄历"Tab
2. 页面顶部显示超大号日期
3. 展示年柱、月柱、日柱（竖排对联样式）
4. 详细的宜忌列表以流式布局展示
5. 底部显示吉神、凶煞、胎神、五行纳音、财神方位等信息
6. 最底部显示"彭祖百忌"警告条

### Edge Cases

- **网络断开**: 用户在无网络环境下打开小程序，应显示缓存的数据或友好的提示信息
- **日期边界**: 用户切换到月份的第一天或最后一天时，应正确处理月份边界
- **农历转换**: 正确处理闰月、节气等特殊农历日期
- **数据为空**: 某些日期可能没有特殊节假日或事件，应显示默认提示
- **倒数日过期**: 对于已经过去的日期，应显示"已过 X 天"
- **日期选择**: 日期选择器应支持未来和过去的日期范围

### Acceptance Scenarios

**场景 1: 首页黄历显示**
- 给定: 用户打开小程序
- 当: 进入首页
- 那么: 应该显示当前日期的公历日期、农历日期、宜忌事项和干支信息

**场景 2: 日期切换**
- 给定: 用户在首页
- 当: 点击左箭头切换到前一天
- 那么: 页面应该更新显示前一天的黄历信息

**场景 3: 月历节假日标记**
- 给定: 用户在月历页面
- 当: 查看包含法定节假日的月份
- 那么: 相应日期单元格应该显示"休"或"班"标记

**场景 4: 添加倒数日**
- 给定: 用户在倒数日页面
- 当: 点击悬浮按钮并填写完整的表单后提交
- 那么: 新事件应该出现在列表中，并显示正确的剩余天数

**场景 5: 详情面板展示**
- 给定: 用户在月历页面
- 当: 点击某个日期
- 那么: 底部应该弹出详情面板，显示该日期的详细宜忌信息

- [ ] 倒数日事件支持自定义颜色标记

## Success Criteria

- **用户体验**: 用户可以在3秒内打开小程序并查看当日黄历信息
- **功能完整性**: 所有5个Tab页面都能正常导航和显示内容
- **交互流畅性**: 日期切换、月份滑动等操作响应时间<300ms
- **视觉一致性**: 所有页面严格遵循设计规范中的色彩系统和布局规则
- **数据准确性**: 黄历数据、节假日数据与官方标准一致
- **倒数日管理**: 用户可以在30秒内添加一个新的倒数日事件
- **兼容性**: 在主流微信版本和iOS/Android系统上正常运行

## Key Entities

### 黄历数据 (AlmanacData)
- **date**: 公历日期 (YYYY-MM-DD)
- **lunar**: 农历日期字符串（如"十月初二"）
- **ganzhi**: 干支信息（如"乙巳年 丁亥月 甲午日"）
- **yi**: 宜事项列表（数组）
- **ji**: 忌事项列表（数组）
- **suitAvoidScore**: 吉凶指数（0-100）
- **额外信息**: 吉神、凶煞、胎神、五行纳音、财神方位、彭祖百忌

### 倒数日事件 (CountdownEvent)
- **id**: 唯一标识符
- **title**: 事件标题
- **description**: 简介（可选）
- **targetDate**: 目标日期
- **type**: 类型（anniversary纪念日 / birthday生日 / countdown倒数日）
- **isLoop**: 是否循环
- **isPinned**: 是否置顶
- **createdAt**: 创建时间

### 节假日 (Holiday)
- **name**: 节日名称
- **dateRange**: 日期范围字符串（如"1月1日-3日"）
- **startDate**: 开始日期
- **endDate**: 结束日期
- **daysCount**: 天数
- **countdown**: 倒数天数
- **note**: 调休说明（如"1月4日(周日)上班"）

## Dependencies & Assumptions

### Dependencies

- **黄历数据API**: 需要接入黄历数据服务（如中华万年历API或自建数据库）
- **节假日数据**: 需要获取国务院发布的法定节假日安排数据
- **Taro框架**: 基于Taro React版本进行跨端开发
- **微信小程序平台**: 依赖微信小程序的基础能力（存储、日期选择器等）

### Assumptions

- 用户主要在中国大陆地区使用，使用中国传统农历和法定节假日
- 用户设备支持微信小程序基础库7.0+
- 黄历数据由第三方API提供或使用预加载的本地数据
- 倒数日数据存储在本地，不需要云端同步（第一版）
- UI参考图提供的布局和交互模式是用户期望的体验
- 色彩系统中的具体颜色值已在开发文档中明确定义

## Out of Scope

以下功能不在第一版范围内：

- 用户登录和账号系统
- 云端数据同步
- 社交分享功能
- 天气信息集成
- 多语言国际化
- 付费功能或广告
- 自定义主题切换（暗黑模式等）
- 小组件或桌面日历
